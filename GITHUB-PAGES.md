# GitHub Pages

Repository: https://github.com/kevinfcohen/Fiberintitiiative

The included workflow publishes the dist directory from the default branch. All app paths are relative and support a repository subpath.

In repository Settings > Pages, select GitHub Actions as the publishing source if Pages is available for your private repository and account plan. Then run Publish Fiber Field Lab from the Actions tab. Use the exact page URL shown by the successful deployment.

No repository visibility change is required by this code. Do not change visibility without the owner's instruction. Only synthetic training examples are included; no AT&T approval or operational network data is represented.

On iPhone: open the published page in Safari, then Share > Add to Home Screen. On Android: open it in Chrome, then Install app or Add to Home screen where supported. First load and offline installation require verification on the actual managed device.

Reference: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
